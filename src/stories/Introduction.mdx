# Vible Arcing components

Stories for the app's UI components live next to each component as `*.stories.tsx`.

Every component follows `DESIGN.md` at the repo root: colours come only from tokens with light, dark and sepia values, rubric red is the only accent, and type is serif-only. The accessibility panel runs axe on each story.
